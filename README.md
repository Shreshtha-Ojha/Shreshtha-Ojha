## Professional Experience

### SenecaGlobal — Python Intern

Contributed to **SGPolaris**, SenecaGlobal's internal platform for running and auto-evaluating technical coding assessments end-to-end.

Architected the GitHub Actions–driven evaluation pipeline in `eval-engine`: candidate repos are cloned, built, and booted in Docker, then run through Vitest (unit/edge), Playwright (E2E), JMeter (load), and ZAP (security) — with results normalized by adapters into weighted competency scores (including an LLM-based scorer) and posted to the platform API.

| Repo | Description |
|---|---|
| [`eval-engine`](https://github.com/SGPolaris/eval-engine) | Automated evaluation engine for candidate code submissions |
| [`platform_api`](https://github.com/SGPolaris/platform_api) | Backend API for the assessment platform |
| [`candidate-portal`](https://github.com/SGPolaris/candidate-portal) | Browser-based coding portal used by candidates during assessments |
| [`LXP`](https://github.com/Shreshtha-Ojha/LXP) | SenecaGlobal's internal Learning Experience Platform — full talent-development lifecycle from learning and skill validation to career pathing and workforce intelligence (Next.js, Node.js, PostgreSQL) |
